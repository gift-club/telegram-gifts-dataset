Wie die Daten erhoben werden

  • Preise werden abgelesen, nicht umgerechnet. Jeder App-Store-Preis ist die Zahl, die Apple auf der Telegram-Seite des jeweiligen Landes in dessen Währung anzeigt, am Datum der Spalte checked.
  • Fragment-Preise (Telegrams eigener Marktplatz) stammen von fragment.com in US-Dollar.
  • Die Auflagen der Sammlergeschenke stammen von den Geschenkseiten auf Fragment. Es sind Messwerte: Die Auflage einer Kollektion kann noch wachsen.
  • Limitierte Geschenke stammen aus dem öffentlichen Log @GiftChanges, das am 24. Oktober 2024 begann. Früher verkaufte Geschenke haben kein Erscheinungsdatum.
  • Dollar-Schätzungen (*_usd_estimate) nutzen die Zentralbankkurse aus fx-rates.json, nie einen Live-Kurs.

Fragen

Ist das ein offizieller Telegram-Datensatz?

Nein. Gift Club liest die öffentlichen Quellen von Telegram (App Store, Fragment, Bot API und das öffentliche Geschenk-Log) und hält jede Zahl mit Datum und Quelllink fest. Telegram veröffentlicht keine solche Liste.

Darf ich die Daten in einem Artikel, einer App oder einer Studie nutzen?

Ja. Die Daten stehen unter CC BY 4.0: Nutze sie überall, auch kommerziell, solange du Gift Club nennst und diesen Datensatz verlinkst.

Wie viel kostet ein Telegram-Stern in Dollar?

0,015 $ auf Fragment bei jeder Menge ab 50 Sternen und etwa 0,0199 $ in einem 100-Sterne-Paket im US-App-Store. Ein von einem Kanal verdienter Stern wird mit 0,013 $ ausgezahlt.

Wie oft wird aktualisiert?

Jede Tabelle trägt das Datum, an dem sie gelesen wurde. Ändert sich ein Preis oder eine Zahl, wird die Zeile an der Quelle neu gelesen und das Datum wandert mit.
